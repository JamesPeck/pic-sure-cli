# pic-sure config show

Print the stack's config, defaults included

```
pic-sure config show
```

## Examples

```
  # Print pic-sure.yaml as validated
  pic-sure config show

  # Print the config as JSON
  pic-sure config show --json
```

The [global flags](pic-sure.md#flags) apply too.

See also: [`pic-sure config`](pic-sure_config.md)
