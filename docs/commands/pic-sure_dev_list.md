# pic-sure dev list

List the services that have a dev mode

```
pic-sure dev list
```

## Examples

```
  # List the services with a dev mode, and their debug ports
  pic-sure dev list

  # The same, as JSON
  pic-sure dev list --json
```

The [global flags](pic-sure.md#flags) apply too.

See also: [`pic-sure dev`](pic-sure_dev.md)
