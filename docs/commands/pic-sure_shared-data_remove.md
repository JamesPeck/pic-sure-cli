# pic-sure shared-data remove

Remove a data set no container uses

```
pic-sure shared-data remove NAME
```

## Examples

```
  # Remove a data set no container uses
  pic-sure shared-data remove nhanes-2026

  # The same, as JSON
  pic-sure shared-data remove nhanes-2026 --json
```

The [global flags](pic-sure.md#flags) apply too.

See also: [`pic-sure shared-data`](pic-sure_shared-data.md)
