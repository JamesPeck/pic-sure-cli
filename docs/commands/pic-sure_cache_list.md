# pic-sure cache list

List cached sources, images and downloads, and what uses them

```
pic-sure cache list
```

## Examples

```
  # Show what the shared cache holds and which stacks use it
  pic-sure cache list

  # The same, as JSON
  pic-sure cache list --json
```

The [global flags](pic-sure.md#flags) apply too.

See also: [`pic-sure cache`](pic-sure_cache.md)
